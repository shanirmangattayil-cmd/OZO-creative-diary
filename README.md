# Ozo Creative Diary

Android app for Ozo Creatives: today's work, due dates, edits, client profiles with gallery and portfolio, payments, team contacts, diary and a WhatsApp / Instagram / Facebook / YouTube notification inbox.

**Download:** [Ozo-Creative-Diary.apk](../../releases/latest/download/Ozo-Creative-Diary.apk)

After installing, open the Inbox and tap **Turn on notification access** to see message notifications inside the app. All data stays on the phone.
